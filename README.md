# Acid Ascent 2 · Chopper Rescue

A single-file HTML5 arcade climbing game. Scale a neon mega-tower while shutters slam, drones patrol, acid rises — dodge barrels thrown by a giant ape clinging to the facade, and hop aboard the rescue chopper that hovers at the glowing **H** for a free lift up the tower.

**▶ Play now:** https://arecibo-sys.github.io/acid-ascent-2/

## Features

- Procedurally generated towers across multiple themed levels
- Rescue helicopter pickups (board the glowing H)
- Kong hazard — chest-beating, barrel-lobbing ape on the tower edge
- Sliding shutters, drones, search beams, wind gusts, rising acid tide
- Combo/flow scoring, checkpoints, shields, grip cells
- Full keyboard, touch/swipe and gamepad support — works on phones and iPads

## Run locally

Everything lives in one file — `index.html`. Open it directly in any browser, no build, no dependencies, no network calls.

## Tech

Single-file HTML/Canvas + Web Audio. No frameworks, no external requests.
